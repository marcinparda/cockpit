# Personas

## Persona 1: Marcin — The Self-Optimizer

| Field | Detail |
|---|---|
| **Role** | Primary user, developer, platform owner |
| **Goals** | Track health/mindfulness/growth consistency; see long-term patterns; own data |
| **Pain points** | Logging feels like a chore; one missed day kills streak motivation; no text diary support in most apps |
| **Habit types** | All 3: boolean (running, meditation), numeric (sleep hours, screen time, water), text-diary (journal) |
| **Frequency** | Daily + some weekly habits |
| **Session pattern** | End-of-day batch, ~90 seconds, on phone |

### Key Journey
1. Opens app at ~21:00 after finishing work
2. Scans icon grid — all today's habits visible at once
3. Taps 4-5 boolean habits (instant complete with animation)
4. Taps numeric habit → popup opens → types hours slept → confirms
5. Taps diary habit → text modal opens → writes 2-3 sentences → saves
6. Glances at completion bar (6/8 today) → closes app
7. Weekly: opens habit detail → views monthly heatmap → notes patterns

## Persona 2: Piotr — The Power Customizer

| Field | Detail |
|---|---|
| **Role** | Secondary user, developer, given access by Marcin |
| **Goals** | Design precise custom habits; track numeric data with targets; use graphs to optimize performance |
| **Pain points** | Preset-only apps too limiting; needs precise frequency config; wants target values per habit |
| **Habit types** | Mostly numeric (weight, reps, time on task) + boolean; occasional text |
| **Frequency** | Daily + 3x/week for workout habits |
| **Session pattern** | Sometimes mid-day (post-workout logging); end-of-day batch for rest |

### Key Journey
1. First session: opens preset library → adds 3 presets → creates 5 custom habits
2. Sets numeric targets on workout habits (e.g. "30 min cardio" target = 30)
3. Logs mid-day after gym: opens app → taps workout habits → enters reps and time
4. Evening: quick batch log for daily habits
5. Weekly: opens stats overview → reviews trend graphs → adjusts targets

# docs/tasks/

Per-task history: `spec.md` → `plan.md` → `work-log.md`, one folder per task, named `<date>-<slug>/`. This is a pointer index only — don't list individual tasks here, they change too often; browse the subfolders directly.

- [`development/`](development/) — feature/dev task records
- [`migrations/`](migrations/) — migration task records
- [`product-design/`](product-design/) — product/design task records

See the `cockpit-grill-me` → `cockpit-plan-slices` → `cockpit-fresh-review` flow in [`../../onboarding.md`](../../onboarding.md) for how these get created.

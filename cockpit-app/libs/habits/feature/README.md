# habits-feature

Data-connected Habits containers: the five pages (Today, Habits, Habit detail, Stats, Settings) and the sheets that read or write data (check-in, create/edit habit, manage categories). They call `habits-data-access` hooks and compose `habits-ui` and `shared-react-ui` components.

Tags: `scope:habits`, `type:feature`. The Habits App only routes to these pages.

## Running unit tests

Run `nx test habits-feature`.

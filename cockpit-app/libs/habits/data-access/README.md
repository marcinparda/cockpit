# habits-data-access

Habits API layer: zod schemas, endpoints, TanStack Query hooks and the Web Push key fetch. Also exports `createHabitMock` / `createCategoryMock` test fixtures.

Tags: `scope:habits`, `type:data-access`. Imported by `habits-feature` (never by `habits-ui`).
